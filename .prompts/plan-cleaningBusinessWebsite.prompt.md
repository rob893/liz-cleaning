# Plan: Static Landing Page for Cleaning Business

Create a modern, mobile-responsive static website to advertise a local cleaning service (named "Liz's Cleaning Service") in Cherokee County, GA. The site will emphasize fast load times, SEO optimization, and clear service offerings (residential, commercial, Airbnb turnovers) with transparent flat-rate pricing.

## Steps

1. **Set up project structure** — Choose between plain HTML/CSS/JS (simplest) or Astro (modern, optimal performance), create folder structure for assets, styles, and scripts
2. **Design hero section** — Build eye-catching landing section with business name, tagline, call-to-action button, and mobile-responsive navigation
3. **Create service sections** — Add sections for services (residential, commercial, Airbnb), pricing table (1BR $80, 2BR $110, 3BR $140), service area (Cherokee County), and unique value props (same-day availability, after-clean photos, issue reporting)
4. **Implement contact form & footer** — Build contact form with name/email/phone/service-type fields, add social media links, business hours (Mon/Thu daytime, Tue/Fri mornings), and footer with copyright
5. **Optimize for SEO & performance** — Add meta tags, structured data markup, optimize images (WebP format), minify CSS/JS, ensure mobile-first responsive design with fast loading
6. **Prepare deployment** — Configure for static hosting (Netlify, Vercel, or GitHub Pages), set up custom domain if needed, add analytics tracking

## Further Considerations

1. **Technology choice** — Option A: Plain HTML/CSS/JS (fastest to build, zero dependencies) / Option B: Astro (modern tooling, component-based, best performance) / Option C: Tailwind CSS + Vite (utility-first styling, fast dev experience)

- Answer: Option B: Astro (modern tooling, component-based, best performance) with Tailwind CSS for styling

2. **Booking integration** — Include a simple contact form only, or integrate third-party scheduling (Calendly, Google Calendar Appointments)?

- Answer: simple contact form only for initial launch (along with phone/email contact info)

3. **Photo gallery** — Add before/after cleaning photos section to showcase quality of work?

- Answer: yes, include a small gallery with 3-5 placeholder images

4. **Testimonials** — Include customer reviews/testimonials section for social proof?

- Answer: yes, add 2-3 placeholder testimonials
